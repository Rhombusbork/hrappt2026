# 1단계: 구조 정리

담당은 구조 담당(VS Code)이고, 브랜치는 `structure`다. 이 단계가 `main`에 들어가야 A와 B가 시작할 수 있다.

## 순서와 시간

| 순서 | 작업 | 시간 | 다 됐다고 볼 기준 |
|---|---|---|---|
| S1 | 슬라이드 정의를 `slides.js`로 빼고, 번호 대신 `id`로 관리 | 1시간 | `stage.js`에 `index === 숫자` 비교가 없다 |
| S2 | 새 순서 26장과 예비 2장, 배경 지정 | 30분 | 00_전체계획.md의 표와 순서·문구·배경이 같다 |
| S3 | 글꼴 교체 | 30분 | 한글은 Pretendard, 영문·숫자는 Paperozi로 나온다. 인터넷을 끊어도 같다 |
| S4 | 단계 기능(`data-step`), 큐 공개(`reveal`), 연출 파일 연결 | 1시간 | 연출 파일이 비어 있어도 모든 큐가 동작한다 |
| S5 | 슬라이드별 화면: 학생증, 배너 4개, 빙고 9칸, 15분, 큰 점수판, 1위, Break Time, 양피지, Happy 2026 | 1.5시간 | 아래 "슬라이드별 상세"를 만족한다 |
| S6 | 사회자 창(`cues.js`, `presenter.js`)을 `id` 기준으로 | 30분 | 사회자 창의 대사·다음 화면·장면 진행 이름이 맞다 |
| S7 | 26장 전체 캡처 점검, README 갱신 | 30분 | 글자가 넘치거나 겹치는 장이 없다 |

## S1. `slides.js`

슬라이드 하나는 객체 하나다.

```js
{
  id: 'houses',            // 코드에서 부르는 이름. 바꾸지 않는다
  chapter: '기숙사 배정',   // 위에 작게 나오는 글(eyebrow)과 식순 목록 이름
  title: '',               // 큰 제목. 비우면 안 나온다
  description: '',         // 설명 한 줄
  theme: 'center',         // hero | center | bare(글자·틀 없음) | blackout
  scene: 'p06',            // scenes/p06.webp. 여러 개면 앞의 것이 없을 때 뒤의 것을 쓴다
  body: 'houses',          // 화면 가운데 내용을 그리는 함수 이름(stage.js의 sceneBodies)
  steps: 4,                // 단계가 있으면 단계 수. 'auto'면 data-step 요소 수
  stepLabel: '배너 내리기', // 사회자 창의 장면 진행 버튼 이름
  reveal: '봉인 열기',      // 큐를 누르기 전까지 .reveal-target을 숨긴다
  cue: '15초 시작',        // 화면 안의 [data-cue] 버튼을 누르는 큐
  effect: 'banners',       // effects/banners.js에 등록된 연출
  spare: true,             // 예비 슬라이드
}
```

- 사진 퀴즈와 영상 파일은 지금 `'11:1'`, `'14:video'`처럼 슬라이드 번호로 저장한다. 이걸 `'child:1'`, `'adult:1'`, `'video'`로 바꾼다.
- 주소의 `#p4`는 그대로 쓴다. 예비 슬라이드는 `#opening`, `#students`처럼 `id`로 연다.

## S3. 글꼴

```css
@font-face{font-family:Pretendard;src:url(fonts/PretendardVariable.woff2) format("woff2-variations");font-weight:45 920;font-display:swap}
@font-face{font-family:Paperozi;src:url(fonts/Paperlogy-7Bold.woff2) format("woff2");font-weight:700;font-display:swap;unicode-range:U+0000-00FF,U+2000-206F,U+2100-214F}
/* 400, 600, 800도 같은 방식 */
--font: Paperozi, Pretendard, system-ui, sans-serif;
```

- 지금 글꼴이 지정된 18곳(고운바탕, Georgia, system-ui)을 모두 `var(--font)`로 바꾼다.
- `GowunBatang-Bold.woff`와 `OFL.txt`는 지운다. 대신 `fonts/LICENSE-Pretendard.txt`를 넣고, 페이퍼로지의 라이선스 안내(OFL, 산돌구름 기준)를 README에 적는다.
- 명조에서 고딕으로 바뀌면 같은 크기에서도 글자 폭이 넓어진다. S7에서 넘치는 곳을 다시 본다.

## S4. 큐 처리 순서

장면 진행(스페이스바, 사회자 창 버튼)을 누르면 아래 순서로 처리한다. 처리되면 거기서 멈춘다.

1. 연출 파일의 `cue()`가 `true`를 돌려주면 끝
2. `reveal`이 있고 아직 공개 전이면 `.reveal-target`을 보여 주고 `.cue-revealed`를 붙인다
3. `steps`가 있고 남은 단계가 있으면 다음 `[data-step]`에 `.is-shown`, `.is-current`를 붙인다
4. 화면 안에 `[data-cue]` 버튼이 있으면 누른다
5. 표지(`cover`)는 다음 슬라이드로 넘어간다

`api.reveal()`도 만든다. 연출 파일이 애니메이션을 끝낸 뒤 2번 공개를 직접 부를 때 쓴다(필름, 문).

## 이 단계에서 하지 않는 것

배와 부엉이, 필름, 문, 상자, 별빛 같은 움직임은 A·B 몫이다. 구조 단계에서는 연출이 없어도 화면과 큐가 끝까지 동작하게만 만든다.
