# HRA 2026 송년회 HTML 발표

Edge 또는 Chrome에서 `index.html`을 열면 실행됩니다. 폴더를 통째로 받아 압축을 풀어 주세요. 인터넷 연결 없이도 슬라이드, 이미지와 한글 글꼴을 읽을 수 있습니다.

- 좌우 방향키로 이동하고 `F`로 전체화면을 엽니다.
- **사회자** 버튼으로 별도 창을 열면 장면별 대사와 진행 큐가 나옵니다. 무대 화면을 전체화면으로 띄운 뒤 사회자 창에서 슬라이드 이동, 자막, 정답 공개와 타이머를 제어할 수 있습니다.
- **운영 패널 → 사진과 영상 준비**에서 사진 퀴즈와 활동 영상 자료를 등록합니다. 선택한 미디어는 현재 탭에 유지됩니다.
- 이름, 문제, 사진은 시연 자료입니다. 점수와 내빈 명단은 브라우저에 저장됩니다.
- 고운바탕 Bold는 SIL Open Font License 1.1로 배포합니다. 배포 조건은 [OFL.txt](OFL.txt)를 참고해 주세요.
