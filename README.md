# HRA 2026 송년회 HTML 발표

Edge 또는 Chrome에서 `index.html`을 열면 실행됩니다. 폴더를 통째로 받아 압축을 풀어 주세요. 인터넷 연결 없이도 슬라이드, 이미지와 글꼴을 읽을 수 있습니다.

- 좌우 방향키로 이동하고 `F`로 전체화면을 엽니다. 스페이스바는 장면 진행(봉인 열기, 배너 내리기, 정답 공개 등)입니다.
- **사회자** 버튼으로 별도 창을 열면 장면별 대사와 진행 큐가 나옵니다. 무대 화면을 전체화면으로 띄운 뒤 사회자 창에서 슬라이드 이동, 자막, 정답 공개와 타이머를 제어할 수 있습니다.
- **운영 패널**(`O`)
  - 기숙사 점수를 입력합니다.
  - 내빈 학생증 명단을 추가·수정·숨김합니다. 초대장에서 저장한 학생증 이미지를 넣으면 그 이미지가 나옵니다.
  - 어린 시절 퀴즈에 쓸 교수님 번호, 사진, 활동 영상을 등록합니다. 선택한 미디어는 현재 탭에만 유지됩니다.
- 이름, 문제, 사진은 시연 자료입니다. 점수와 내빈 명단은 브라우저에 저장됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `slides.js` | 슬라이드 순서, 화면 문구, 배경, 큐. 빙고 문항, 수상자, 필름 사진 목록 |
| `cues.js` | 사회자 멘트, 무대 지시, 자막 |
| `stage.js`, `stage.css` | 화면 그리기와 진행 |
| `effects/` | 슬라이드별 연출. 작업계획/04_협업방법.md 참고 |
| `art/` | 초대장(hra26yep.vercel.app)의 기숙사 문장과 밀랍 인장 |
| `작업계획/` | 개편 계획과 작업 분담 |
